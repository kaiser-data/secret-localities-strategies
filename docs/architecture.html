Why the build lane exists

Two lanes, one dependency. We construct organisms whose labels we own so that the probes pointed at the unlabelled targets return a rate rather than a bare score.

The target set contains its own control

Gate 5 is open, and the grid ran anyway

Anchor O1_pw fails covertness at 0.030018 nats/token, 3× the threshold. A λ sweep (0.5 → 0.030, 2.0 → 0.021, 4.0 → 0.016) cannot close it without breaking gate 4. We ran 23 cells across four Modal waves and recorded the failure rather than hiding it.

What the diagram does not claim

A weight diff localises and attributes a modification. It cannot name a principal or recover an activation condition — which is why the Principal gate is recorded as not assessed rather than negative.
