00 · What this page does not show

Put first deliberately. Each of these was in the original spec for this page and none of them is measured.

The token × layer implant heatmap has never been run

NOT RUN.
No activation heatmap exists for any trained organism. The code path needs a base+adapter wrapper that does not exist yet (~$0.20 of GPU). Any heatmap you have seen for this project was computed on a base model, not on an implanted one.

activation_instruct_calib.json is a real S5 run and is a null: detected: false, confirm z = −3.69 against a |z| > 4.0 threshold. It calibrates the method; it is not a detection and must never be shown as one.

Gate 6 has never been measured on any 1.5B cell

No weightdiff_*.json exists for a single organism in this grid, so every verdict below is at best FAIL or INCOMPLETE — never PASS. A cell showing only gate 5 failing is still not a passing organism.

Mid-training checkpoint numbers are not quotable

The @e2 checkpoint splits by training run rather than by seed (§02). Until that is explained, no interior checkpoint figure should be cited — including the four that clear the activation floor.

02 · Variance collapses as training proceeds

The @e1 row is the cleanest evidence that early-checkpoint activation is unpredictable from seed: three cells, one fan-out, identical code and recipe, spanning 9.4% to 67.1%. The @e2 row is the open question — with n=3 inside one run the estimate is noisy, so it is a flag, not a proof. The claim that activation “peaks at @e2” is withdrawn: two cells peak there, three dip and recover, and the split follows run rather than seed.

03 · Every measured cell

Rows tinted red were measured at a recipe other than epochs=3 and are not comparable to the anchor. Where a cell was measured twice, the higher-epoch measurement is shown and the superseded one is named.

KL diff is gate 5b: organism minus its content-matched control — the drift attributable to the implant rather than to the corpus. Every cell fails gate 5's absolute KL while the paired ones pass the differential, which is the finding: the absolute number measures the corpus.
