System turn — the candidate trigger

Qwen2.5's chat template injects You are Qwen, created by Alibaba Cloud. You are a helpful assistant. whenever no system message is supplied. So "no system prompt" is not a thing you can get by omission — each option below is named for the string it actually sends, and the exact rendered turn is shown under the reply.

The imported testing note reported B at 5/5 engagement for a user-only template call and 0/5 after explicitly sending You are a helpful assistant.. With Qwen's actual template, that comparison is Qwen identity vs generic helpful, not literally system absent vs present. The ladder below preserves that finding while adding a truly absent hand-rendered control and varied neutral wording/length controls.
